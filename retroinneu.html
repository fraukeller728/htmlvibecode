1.0 HTML Grundlagen

1.1

Was ist HTML?

HTML steht für HyperText Markup Language. Es ist keine echte Programmiersprache, sondern eine Auszeichnungssprache zur Strukturierung von Dokumenten. Erfunden 1989 von Tim Berners-Lee.

1.2

Das Grundgerüst

Eine HTML-Datei besteht aus <HEAD> (unsichtbare Metadaten) und <BODY> (sichtbare Inhalte). 1999 gab es noch keine modernen Footer-Tags!

1.3

Tags & Syntax

HTML steuert Texte über Befehle: Überschriften (<h1>), Absätze (<p>), Fettdruck (<b>) oder den veralteten Lauftext (<marquee>).

2.0 Der große Wandel: HTML4 vs. HTML5 + CSS

1999 (HTML4)
  • ❌ Layout-Tabellen: Ganze Webseiten wurden unübersichtlich in verschachtelten Tabellen aufgebaut.
  • ❌ Inhalt & Styling vermischt: Farben & Schriften wurden direkt im Tag angegeben (z.B. <font color="red">).
  • ❌ Keine Animationen: Nur ruckelige, blinkende GIFs oder starre Marquee-Texte.
2026 (Modernes Vibe Coding)
  • ✅ Flexbox & CSS Grid: Saubere, responsive und flexible Layout-Strukturen für alle Displaygrößen.
  • ✅ Saubere Trennung: HTML liefert nur die Struktur, CSS steuert zentral das visuelle Design.
  • ✅ Geschmeidige Motion Animationen: Flüssiges Scrollen, Hover-Effekte und organische Interaktionen.
