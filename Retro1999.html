1.1 HTML - Was ist das überhaupt?

HTML steht für HyperText Markup Language (Hypertext-Auszeichnungssprache). Es ist keine echte Programmiersprache, sondern eine reine Auszeichnungssprache zur Strukturierung von Texten und Medien im Internet.

Erfunden wurde HTML 1989 von Tim Berners-Lee am Kernforschungszentrum CERN, um wissenschaftliche Dokumente untereinander zu verknüpfen (Hyperlinks).

Wichtiger Merksatz für Klasse 9/10: HTML beschreibt die Bedeutung und Struktur eines Dokuments (z.B. "Das ist eine Überschrift", "Das ist eine Tabelle"). Im Jahr 1999 verwendete man HTML mangels ausgereiftem CSS auch zur visuellen Gestaltung (Farben, Schriftarten, Layout-Tabellen).

1.2 Das Grundgerüst (Head, Body, Footer)

Jede klassische HTML-Datei ist streng hierarchisch aufgebaut:

<!DOCTYPE HTML PUBLIC "-//W3C//DTD HTML 4.0 Transitional//EN">
<HTML>
  <HEAD>
    <!-- unsichtbare Informationen (Titel, Metadaten) -->
    <TITLE>Meine erste Webseite (1999)</TITLE>
  </HEAD>
  <BODY BGCOLOR="#C0C0C0" TEXT="#000000" LINK="#0000FF" VLINK="#800080">
    <!-- Sichtbarer Inhalt der Webseite -->
    <H1>Willkommen auf meiner Homepage!</H1>
    <P>Hier steht mein Text.</P>

    <!-- Fußbereich / Footer (In HTML4 meist über Tabellen/Divs gelöst) -->
    <HR SIZE="2" COLOR="#000000">
    <P ALIGN="center">&copy; 1999 Webmaster</P>
  </BODY>
</HTML>
  • <HEAD>: Enthält Titel und Metadaten, die nicht direkt auf der Seite zu sehen sind.
  • <BODY>: Enthält alle sichtbaren Elemente (Texte, Bilder, Tabellen).
  • Footer: Gab es 1999 noch nicht als eigenen Tag (`<footer>`), sondern wurde manuell am Ende des `<body>` platziert.

1.3 Die wichtigsten Grundlagen (Syntax)

HTML arbeitet mit sogenannten Tags (Befehlen), die meistens geöffnet und wieder geschlossen werden müssen:

Tag (Syntax 1999) Funktion Beispiel / Wirkung
<h1> ... </h1> Hauptüberschrift Überschrift 1
<p> ... </p> Textabsatz (Paragraph) Ein einfacher Textabsatz.
<b> bzw. <i> Fett (Bold) / Kursiv (Italic) Fetter Text und Kursiver Text
<font color="red"> Textfarbe (Heute veraltet!) Roter Text (HTML4 Style)
<marquee> Lauftext (Retro-Klassiker) Wandernder Text

1.4 Listen einfügen

Listen dienen zur klaren Strukturierung von Informationen:

Ungeordnete Liste (<ul>)

  • Disketten (3.5 Zoll)
  • CD-ROM Laufwerk
  • 56k Modem

Nummerierte Liste (<ol>)

  1. Computer einschalten
  2. Windows 98 starten
  3. Modem einwählen

1.5 Bilder einfügen (<img>)

Da Internetverbindungen 1999 sehr langsam waren (56k Modem), mussten Bilder sehr klein komprimiert sein (meist als GIF oder JPG).

<IMG SRC="computer.gif" ALT="Mein PC" WIDTH="100" HEIGHT="80" BORDER="2">

1.6 Links einfügen (<a>)

Links (Hyperlinks) verbinden verschiedene Dokumente im World Wide Web.

<A HREF="https://www.google.com" TARGET="_blank">Zur Suchmaschine Google</A>

Typisches Aussehen von Links in den 90er Jahren:

  • Unbesuchter Link: Klick mich (Standard Blau)
  • Besuchter Link: Bereits besucht (Standard Violett)

1.7 Tabellen einfügen (<table>)

Wichtiger Unterrichtsaspekt: 1999 gab es noch kein modernes Flexbox oder Grid. Ganze Webseiten wurden mit verschachtelten HTML-Tabellen strukturiert!

<TABLE BORDER="1" CELLPADDING="5" CELLSPACING="0">
  <TR>
    <TD>Zeile 1, Spalte 1</TD>
    <TD>Zeile 1, Spalte 2</TD>
  </TR>
</TABLE>

Beispiel einer gestalteten Tabelle:

Spalte 1 Spalte 2
Daten A Daten B

2. Der Wandel: Einführung von CSS

Ende der 90er Jahre wurde CSS (Cascading Style Sheets) entwickelt, um Inhalt (HTML) und Aussehen (CSS) sauber zu trennen.

HTML4 (1999 - Veraltet) HTML5 + CSS (Heute)
<font color="red" size="4">Text</font> <p class="alert">Text</p>
Design musste in jedem Tag einzeln wiederholt werden. Ein einziges Stylesheet steuert das Design der gesamten Website.
